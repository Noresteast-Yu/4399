# 地铁跑酷换乘助手 - 第2周数据模块提交

## 模块范围

本版本属于微信小程序 `miniprogram` 中的“数据整理与静态资源开发模块”。

本周在第一周基础版上继续迭代，重点是：

- 增加数据版本元信息
- 补充10号线“虹桥火车站 -> 同济大学”连续站序
- 修正部分站点换乘信息
- 保持数据查询接口和演示页可运行

## 当前默认演示

- 默认出发站：上海虹桥火车站
- 默认线路：上海地铁10号线
- 默认方向：往基隆路方向

## 本周新增

- 新增 `miniprogram/data/dataMeta.js`
- `routeManager.js` 新增 `getDataMeta()`
- `dataValidator.js` 增加数据元信息校验
- `lineStations.js` 新增“同济大学”站
- `stations.js` 新增“同济大学”站
- 修正“海伦路”为10号线与4号线换乘站
- 将“新天地”规范为“一大会址·新天地”

## 数据说明

当前数据为课程项目静态演示数据，站序参考公开上海地铁10号线站点信息人工整理。

本项目当前没有实现实时爬虫、联网请求或数据库同步，因此数据不代表完整真实运营数据，也不包含官方实时运营状态。

## 运行方式

使用微信开发者工具导入本文件夹，编译运行即可。

如果没有正式 AppID，可以使用测试号或无 AppID 模式运行。
